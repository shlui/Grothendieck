# Portable accepted R3 source cells

Run from any extracted directory:

```bash
python3 verify_all.py
```

The complete replay checks every stored physical-moment/q partition leaf, exact q>=64 tails, exact spectral gates, frozen centering/covariance terms, and continuous outer source prices. Python 3, NumPy, python-flint, and the system MPFR shared library are required. No optimizer, network, archived discovery imports, or absolute workspace path is used. `python3 verify_all.py --quick` checks immutable relative hashes, all exact tails and outer prices, using the included previously accepted all-q records as premises. Replay logs and JSON are in `replay_outputs/`.

The original local arithmetic and independent partition checkers are copied unchanged. Two copied outer auditors have path-only adapters so ledger keys resolve relative to this extracted directory. All ledger SHA256 keys and the package manifest are relative. Unused provenance metadata may retain original locations.

These are **restricted source-domain certificates**, not a global norm theorem. They include the lower-amplitude all-q profiles, the full-E profiles and constrained-r bands, and the diffuse small-cumulant profiles. The earlier diffuse mask does not cover the newer b=.7171 witness; a separate frozen profile and new upper-source mask are supplied. Each mask's lower r boundary remains an actual restriction. Native complementary gates and their exact domain union must be proved separately before asserting a new Grothendieck endpoint.

The analytic premises are the physical polarization/source reduction, Gaussian Bessel constraints, the six-gate residual projection theorem, the independently proved cubic moment/Wick 633 bound, and complete-line cubic L1 Stein rows. This package replays the L1 shape-price cover from frozen accepted scalar rows; it does not independently reprove their complete-line scalar inequalities or the Wick tensor theorem. The main research archive supplies those proofs. The signed-matrix transfer from an all-sign operator bound is a separate step.

The candidate family is S_b=P1-b P3. The inherited accepted lower endpoint is 1.773. Values near 1.775 from adversarial sign tests are discovery evidence only. The constrained cells here prove no improved global endpoint by themselves.

The additional targeted profiles are independently accepted whole-q gates. Run
`python3 verify_targeted.py` for their fresh complete partitions, exact tails,
and independently expanded restricted source-box prices. `--quick` checks tails
and source prices using the frozen accepted body/exterior records. The full-E
whole-q auditor runs in a temporary copy so accepted input reports remain immutable.
The added source boxes also do not assert a global norm bound.

Additional accepted gates: moderate15, primary18, lower19, next20, and lower-diffuse21.
Run `python3 verify_expanded.py` to freshly replay all five complete q partitions
and exact tails, and re-evaluate all eighty restricted-source corners with the
independently derived expanded price formula. Run `python3 verify_expanded.py --all`
to replay the earlier targeted gates too. All paths are relative; no optimizer,
archive, network, or original workspace is used. These restricted source boxes
alone do not assert complete global source coverage or a new lower endpoint.
