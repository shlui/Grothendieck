# A compact completion for the discarded mixed cubic agreement projection

This is an exact additional constraint for the physical Gaussian sign
geometry. It does not assert that the middle-amplitude region is closed.
It retains a negative mixed cubic component of \(h\), and eliminates
its second-chaos source using existing scalar shape parameters.

## 1. The physical second-chaos source

Let \(f,g\) be odd signs, \(h=(f+g)/2\), \(k=(f-g)/2\),
\(P_1h=uZ\), and let \(W\) denote the independent transverse
Gaussian coordinates. Set
\[
A(W)=\mathbb E_Z[Zh(Z,W)],\qquad
k_0(W)=\mathbb E_Zk(Z,W),\qquad
r=\|P_3^Wk_0\|_2.
\]
For \(r>0\), put \(Q=P_3^Wk_0/r=I_3(F)\), normalized by
\(6\|F\|^2=1\). Write
\(G=F\otimes_2F\), \(s=\|G\|_F^2>0\), and
\[
R_2=\frac{I_2(G)}{\sqrt{2s}},\qquad
\kappa=\mathbb EQ^4-3,
\qquad D=1+\frac{3\|\operatorname{Sym}(F\otimes_1F)\|^2}{2s}.
\]
The matrix \(G\) is positive semidefinite. In particular \(R_2\)
is a centered positive weighted sum of Gaussian squares, not an
arbitrary normalized second-chaos law. The product formula gives
\[
\mathbb ER_2=0,\quad \mathbb ER_2^2=1,\quad
\lambda:=\mathbb EQ^2R_2=18\sqrt{2s}
=\sqrt{\frac\kappa{2D}}.
\tag{1}
\]
Here \(P_2(Q^2)=18I_2(G)\), and \(\kappa=1296sD\).
Also, with \(U=\|DQ\|^2/3-1\),
\(\mathbb EUR_2=12\sqrt{2s}=2\lambda/3\).

The function \(ZR_2(W)\) is a unit vector in total Hermite degree
three and is orthogonal to the purely longitudinal \(H_3(Z)\).
Therefore, for \(b>0\), the operator's agreement penalty contains
the separate term
\[
-b\|P_3h\|_2^2\le
-b\bigl(\mathbb E[H_3(Z)h]\bigr)^2-bt^2,
\qquad t=\mathbb E[A R_2].
\tag{2}
\]
The mixed term in (2) was discarded by a completion retaining only
\(H_3(Z)\).

## 2. An exact one-source inequality

The physical conditional diamond implies
\[
A^2+\nu^2k_0^2\le\nu^2,\qquad \nu^2=2/\pi.
\tag{3}
\]
Let \(v\ge\nu^2\) be a fixed scalar; the rational choice
\(v=637/1000\) is sufficient. Then
\(A^2\le v(1-k_0^2)\).
For arbitrary real \(a,c\), put \(\eta(Q)=a+cQ^2\). Since
\(\mathbb E\eta(Q)R_2=c\lambda\), Cauchy--Schwarz gives
\[
\mathbb E(A-\eta(Q))^2\ge(t-c\lambda)^2.
\]
For any \(\mu>0\), completing the scalar square in \(t\) yields
\[
bt^2+\frac\mu v(t-c\lambda)^2
\ge\frac{b\mu}{\mu+bv}c^2\lambda^2.
\]
Consequently
\[
-bt^2\le\frac\mu v\mathbb E(A-\eta(Q))^2
-\frac{b\mu}{\mu+bv}c^2\lambda^2.
\]
Expanding, using (3), and using \(\mathbb EQ^4=3+\kappa\)
proves the compact physical constraint
\[
\boxed{\begin{split}
-bt^2\le{}&\mu-\mu\mathbb Ek_0^2
-\frac{2\mu}{v}\mathbb E[(a+cQ^2)A]\\
&+\frac\mu v\{a^2+2ac+c^2(3+\kappa)\}
-\frac{b\mu c^2\kappa}{2D(\mu+bv)}.
\end{split}}
\tag{4}
\]
It introduces no free amplitude for \(R_2\), no additional source
law, and no additional shape parameter beyond \(\kappa,D\).
The last term is a strictly negative mixed-moment credit when
\(c\ne0\) and \(\kappa>0\). It vanishes on the diffuse Gaussian
source boundary \(\kappa\to0\), as expected.

## 3. Direct insertion into the existing local criterion

Suppose an existing spectral comparison and longitudinal completion
bound the operator pairing by
\[
C_0+\mathbb E\mathcal L(Q;h,k)-bt^2,
\]
where, conditionally on \(W\),
\[
\mathcal L(q;h,k)=2\ell A+2\beta h_3+k^TMk
+2q\,\omega^Tk-2\delta\mathbb E_Zh^2,
\quad k=(k_0,k_1,k_2,k_3)^T.
\]
The normalized longitudinal Hermites define these four coefficients,
and \(h_3=\mathbb E_Z[H_3(Z)h]\).
The mixed term in (2) must be unused in \(C_0\); it cannot be
counted twice if another completion already retained that direction.

Equation (4) gives exactly the same one-source local problem with
\[
\boxed{\quad
M_\mu=M-\mu e_0e_0^T,\qquad
\ell_\mu(q)=\ell-\frac\mu v(a+cq^2).
\quad}
\tag{5}
\]
Add to the outer price only
\[
\boxed{\quad
\mu+\frac\mu v\{a^2+2ac+c^2(3+\kappa)\}
-\frac{b\mu c^2\kappa}{2D(\mu+bv)}.
\quad}
\tag{6}
\]
Thus a global scalar majorant for the modified potential has the
same four local moment coordinates and a single scalar source \(q\).
The longitudinal coefficient now depends quadratically on \(q\),
but the fixed matrix and all outer prices remain explicit. With
rational \(v,a,c,\mu\), the frozen data in (5)--(6) are rational
apart from the already-existing shape parameters.

When \(M_\mu\succeq0\), the usual positive quadratic-completion
formula applies directly. Even if it is indefinite, a bounded local
moment-box upper bound remains valid: choose the actual physical
moment vector inside the box before taking the supremum. The
indefinite matrix may substantially loosen that box relaxation, so
numerical success must still be verified on its complete domain.

## 4. A version leaving the local matrix unchanged

The exact source projection implies
\(\|k_0\|_2^2\ge r^2\). Replacing the negative term in (4) by
\(-\mu r^2\) gives another valid criterion. Keep \(M\) unchanged,
use the same \(\ell_\mu(q)\), and add the price
\[
\mu(1-r^2)+\frac\mu v\{a^2+2ac+c^2(3+\kappa)\}
-\frac{b\mu c^2\kappa}{2D(\mu+bv)}.
\tag{7}
\]
This version preserves the positive matrix used by the frozen local
oracle and uses the actual projection amplitude \(r\), rather than
a generic law constraint. It is weaker than (4) but easier to insert
into an existing profile search.

Neither criterion claims improvement automatically. In particular,
the physical ellipse can have slack and the modified potential must
be globally majorized. A fit on the representative
Gaussian-plus-Hermite source law is discovery evidence only. The
complete scalar and local covers remain the acceptance condition.

## 5. A rigorous replacement for convex source chords

The quadratic dependence of \(\ell_\mu(q)\) destroys the automatic
convexity in \(q\) of a local potential with a linear source. It is
therefore incorrect to reuse ordinary endpoint chords without a
between-node allowance.

In the criterion above, before maximization each fixed physical line
assignment and each fixed local moment-box point contributes a
quadratic function of \(q\). The added quadratic coefficient is
\(-2\mu cA/v\), with \(|A|\le\nu\). Hence its second derivative
is at least \(-4\mu|c|\nu/v\), uniformly over all candidates.
It follows that
\[
\Phi_\mu(q)+\frac{2\mu|c|\nu}{v}q^2
\quad\text{is convex.}
\]
For \(q\in[q_0,q_1]\), one thus has the exact upper bound
\[
\boxed{\quad
\Phi_\mu(q)\le\operatorname{Chord}_{q_0,q_1}\Phi_\mu(q)
+\frac{2\mu|c|\nu}{v}(q-q_0)(q_1-q).
\quad}
\tag{8}
\]
The maximal extra allowance is
\(\mu|c|\nu(q_1-q_0)^2/(2v)\). For rational acceptance,
\(\nu\) may be replaced by \(798/1000\). If a baseline residual
correction already has a curvature allowance, add this new allowance
to that existing bound rather than presuming baseline convexity.

The old purely linear source tail also needs adjustment. The physical
local supremum changes by at most
\(2\nu|\ell_\mu(q)-\ell|\) when only the longitudinal coefficient
changes. Thus an old bound \(C+L|q|\) becomes the safe tail bound
\[
C+L|q|+\frac{2\mu\nu}{v}(|a|+|c|q^2).
\tag{9}
\]
The matrix subtraction in (5) cannot increase the physical local
objective, so (9) is also a valid coarse tail for that version.
It has quadratic growth and can be incorporated into the existing
sextic polynomial/Stein tail comparison. Formula (9) concerns the
physical supremum; an artificially enlarged box-dual supremum may
require its own separate tail audit.
