# R3 cell replay

Run from any working directory:

```sh
python3 /path/to/replay_R3_cell/verify_all.py
```

Requirements: Python3, NumPy and a system MPFR shared library.  No optimizer,
SciPy, raw research archive, network connection or floating fit input is
required.  Floating polynomial roots only propose rational surrogates; their
errors receive an exact global allowance before directed acceptance.

The replay reconstructs every recorded local box, checks the complete scalar
line, verifies the exact rational matrix gates and tail, and prices all vertices
of the continuous outer source cell.

For \(S=P_1-(18/25)P_3\), the proved cell is

\[
u\in[.7549,.7551],\qquad r\in[.2574,.2577],\qquad
\kappa\in[.51,.55].
\]

It is uniform over all real Gaussian dimensions, all physical sign functions
with polarization parameters in this cell, every shared tensor shape, and every
real scalar source value.  Its exact upper bound is

\[
\langle Sf,g\rangle\le\frac{28167}{50000}=.56334<\frac{40}{71}.
\]

The underlying tensor moment input is the fresh complete633 proof in the main
research package.  `R3_CELL_THEOREM.tex` gives the precise parameter definitions
and scope.  The present cell does **not** prove a global operator norm bound or
an improved Grothendieck lower bound.  All remaining source parameters must
still be covered and combined with the exterior certificates.

The compact scalar cover has 3376 directed moment-center leaves on \([0,8]\)
and 380 directed corner leaves on \([8,64]\).  An exact shifted sextic proves
the entire tail \([64,\infty)\); reflection covers negative sources.  Independent
replay reports are included beside the code.

Outputs are written to the package's own `results` and `code` directories.

The final replay also checks transported affine source polygons.  The target
polygon has u in [.7538,.7562], kappa in [.3,.8], and
r=.25755-3(u-.755)+t with |t|<=.00025.  Its rounded exact upper cap is
28168/50000=.56336.  The fallback polygons use cap451/800.  These polygons
cover only the stated source subsets, and do not cover all r at those amplitudes.
