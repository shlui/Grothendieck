# Accepted linear-contact source bank

This package supplies additional physical source constraints, independent of
the operator coefficient. It does not by itself prove a Grothendieck endpoint.

The six base contacts use `A=147/50`, `B=0` and contact nodes
`w=1/2,1,2,11/2,10,20`. Sixty rows result from ten positive exact scalings
of these contacts. The accepted global cubic-head contact theorem also holds
when `B=0`. If its polynomial coefficients are `q_(2j)`, scaling the head by
`c>0` scales them by `c^(1-2j)`, because

`J_(cA)(x)=c J_A(x/c)`.

Each row therefore remains a global pointwise majorant. The normalized cubic
moment price is convex in the fourth cumulant and affine in the coupled
shape parameter. One fixed row is selected on an entire source rectangle;
the four moment corners bound its price uniformly. The resulting constraint
is `r <= price - A*u`, decreasing in `u`. All coefficients include the full
Gaussian multiplier; an additional factor `sqrt(2/pi)` must not be inserted.

`source_bank.json` records the 24 rounded base coefficients, 60 scaled rows,
1,800 directed moment prices, and source caps for the 227 frozen unclosed
rectangles. Forty-five lower and 101 upper rectangles obtain a smaller source
upper bound. None of those broad rectangles is wholly excluded by this bank.

The independent replay uses MPFR at 768 bits and checks all coefficients,
scalings, directed prices, source-ledger hashes and selected source caps.

Run from the workspace root:

```sh
python3 tonight/moments/linear_contact_bank/certify_source_bank.py
python3 tonight/audit/verify_linear_contact_bank.py
```

The principal contact package remains unchanged. `SHA256.json` binds this
additional bank, its independent replay, and the source-geometry dependencies.
