# Independent native complement-pricing audit

The transport and pricing formulas in
`tonight/recovery/profile_cover/price_native_complement.py` pass analytic
review. They export conditional source cells, not a global operator bound.

For a frame certified at b0=.72, lowering b to a positive b'<=b0 weakens
each of the b-dependent even/odd PSD gates. All physical matrices and source
coefficients remain fixed. The scalar local potential includes beta²/b;
therefore the constant translation is exactly

`shift = beta²(1/b' - 1/b0)`.

The spectral Gram coefficient is
`g(b')=(nu-M02)²/M22-M00+b'-2delta=g(b0)+(b'-b0)`.
Both signs and normalizations are correct for the native profile's normalized
cubic Hermite coefficient beta. This is distinct from raw-Hermite R3 profiles,
whose cubic constant is6beta²/b. The constant shift does not alter the target
Stein derivative or its whole-line comparison; it adds shift to every target
expectation, including the r=0 endpoint.

For a native row targeting A(r|Q|)-mu|Q|, its uncentered outer price has
`E_gauss A + native_polynomial + eta*V/2 + mu*(rho-c)`,
where c=sqrt(2/pi), mu>=0 and V=E(tau-1)². A pure cubic L1 row supplies
`E|Q| <= c + pure_polynomial + pure_eta*V/2`.
Substituting this bound cancels c exactly. Thus the code correctly replaces
q_j by q_j+mu*pure_q_j and eta by eta+mu*pure_eta, and removes the standalone
mu*(rho-c) term. The new sextic coefficient remains nonnegative and eta
positive. This preserves convexity in kappa and affinity in the shape
coordinate. The selected L1 rows must remain bound to the already accepted
ten pure-|Q| whole-line certificates; this condition is fulfilled by the
frozen refinement ledger and its source hashes.

At each r endpoint, a row is fixed for the entire cumulant band, based on
its four corner prices. Every accepted scalar comparison is pointwise and
contains no kappa parameter, so its original discovery interval imposes no
restriction on repricing. Convexity in kappa and affinity in shape extend the
four endpoint prices to the whole band. The same physical target A is convex
on the half-line. Therefore `E A(r|Q|)` is bounded by the positive chord
between adjacent r endpoints. The code then adds the exact quadratic g*r²
and maximizes that quadratic over each whole r subinterval; a separate
curvature reserve is unnecessary. The maximum in u is at an endpoint because
its remaining cost is u²-2ell*u. Different selected rows at distinct r
endpoints do not invalidate positive chord interpolation.

Both old and new native scalar packages must have exactly the same accepted
physical frame, knot grid, target heights and tail. The code checks these
equalities before combining them. Old scalar profiles receive their original
single height/tail correction, while the new post-inflation rational profiles
receive zero correction. The nonnegative tail correction is paid using the
safe original rho=.849. There is no double diagonal or target repair.

The source-coverage flag compares the final r-grid endpoint with the directed
support maximum at the lower u endpoint. An inward endpoint is explicitly
not promoted to complete source coverage. The final union theorem must check
every unclosed cell against additional accepted R3/support domains and the
physical source bound. The exported boxes by themselves prove no global
Grothendieck endpoint.
